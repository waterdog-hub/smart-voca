# smart-voca

**프로젝트명**: smart-voca
**상태**: 구현 완료 (화면 확인 및 자동 테스트 통과)
**성격**: ICT 폴리텍대학 AI 활용 코딩 실습 과제

## 한 줄 설명

영어 단어장을 관리하고, 설정한 분량에 따라 날마다 암기 진도를 만들어 주며, 객관식·주관식 시험으로 암기 여부를 확인하는 Windows 학습 프로그램입니다.

## 주요 기능

- **단어장**: CSV 파일 불러오기·저장, 단어 추가·수정·삭제, 검색, 열 정렬
- **암기**: 하루 진도(신규·복습·오답)를 카드로 외우기, 진행률, 지난 일차 진도 보기
- **시험**: 객관식·주관식, 영→한·한→영·양방향, 오답 기록, 시험 결과 저장과 정답률 보기
- **설정**: 하루 분량, 오답 기준, 시험 기본 형식·방향

## 기술 스택

| 항목 | 내용 |
|------|------|
| 언어 | Python 3.14 |
| GUI | tkinter (표준 라이브러리) |
| 저장 | CSV 파일 (`data/` 폴더) |
| 외부 패키지 | 없음 |

## 설치 및 실행

Windows에서 Python 3.14가 설치되어 있어야 합니다. 외부 패키지 설치는 필요 없습니다.

1. 프로젝트 폴더로 이동합니다.
   ```
   cd C:\Users\USER\Documents\dev\smart-voca
   ```
2. 프로그램을 실행합니다.
   ```
   py -3 src/main.py
   ```

> 이 PC에서는 `python` 명령이 동작하지 않아 `py -3`을 씁니다.

## 테스트

프로젝트 루트에서 실행합니다.

```
py -3 -m unittest discover -s tests
```

- 단위 테스트 (핵심 로직, 저장소): 39개
- 화면 흐름 테스트 (`tests/test_gui_flow.py`): 8개
- 테스트는 임시 폴더를 쓰므로 `data/` 파일을 바꾸지 않습니다. 화면을 띄울 수 없는 환경에서는 화면 테스트가 건너뛰어집니다.

## 사용 방법

### 단어장 탭
- "CSV 불러오기": 단어 파일을 읽어 단어장을 바꿉니다. 첫 줄은 `word,meaning`이어야 합니다.
- 단어와 뜻을 입력하고 "추가"를 누릅니다. 뜻이 여러 개면 `/`로 구분합니다.
- 단어를 고르고 "선택 수정"을 누르거나 더블클릭합니다.
- 단어를 고르고 "선택 삭제"를 누릅니다. 모든 일차의 진도에서도 빠지며, 학습 기록은 남습니다.
- 검색 칸에 단어나 뜻을 입력하면 걸러서 보여줍니다. 열 제목을 누르면 정렬됩니다.

### 암기 탭
- "다음 일차 만들기": 새 일차의 진도를 만듭니다. 현재 일차를 모두 외운 뒤에 누를 수 있습니다.
- 카드 단축키: **↑** 뜻 보기, **→** 외움, **←** 다시
- "일차별 진도": 지난 일차의 단어와 외움 여부를 봅니다. 읽기 전용입니다.

### 시험 탭
- 형식, 방향, 문항 수를 고르고 "시험 시작"을 누릅니다.
- 객관식은 **1~4** 키로 보기를 고르고, **Enter**로 제출하거나 다음 문항으로 넘어갑니다.
- "시험 기록": 지난 시험 결과와 전체 정답률을 봅니다.

### 설정 탭
- 하루 신규·복습·오답 수, 오답 기준, 시험 기본 형식·방향을 바꿉니다.
- 저장하면 다음 일차 진도부터 적용됩니다. 이미 만든 진도는 바뀌지 않습니다.

## 데이터 파일

| 파일 | 내용 | Git |
|------|------|-----|
| `words.csv` | 단어장 (`word,meaning`) | 샘플 1988개 포함 |

| `day_plan.csv` | 일차별 진도 | 제외 (개인 학습 기록) |
