# smart-voca

**프로젝트명**: smart-voca
**상태**: 회원제 웹 서비스 구현 중 (M6 완료). 가입부터 암기, 시험까지 동작합니다. 시연 환경은 구현했고 실제 ngrok 리허설이 남았습니다. 1단계 Windows 데스크톱 앱은 구현을 마쳤습니다
**성격**: ICT 폴리텍대학 AI 활용 코딩 실습 과제. 제출은 프로그램 시연과 PPT 발표이며, 시연 대상은 웹 서비스입니다

## 한 줄 설명

회원마다 자기 단어장을 관리하고, 설정한 분량에 따라 날마다 암기 진도를 만들어 주며, 객관식·주관식 시험으로 암기 여부를 확인하는 영어 단어 학습 서비스입니다.

## 설치 및 실행

Windows에 Python 3.15가 설치되어 있어야 합니다. 명령은 모두 프로젝트 루트에서 실행합니다.

> 이 PC에서는 `python` 명령이 동작하지 않아 `py -3`과 `.venv\Scripts\python`을 씁니다.

### 웹 서비스

1. 가상환경을 만들고 패키지를 설치합니다. 테스트를 실행할 때도 이 준비가 필요합니다.
   ```
   py -3 -m venv .venv
   .venv\Scripts\python -m pip install -r requirements-dev.txt
   ```
2. 설정 파일을 복사합니다. `DATABASE_URL`이 없으면 앱이 시작되지 않습니다.
   ```
   copy .env.example .env
   ```
3. DB를 만듭니다.
   ```
   .venv\Scripts\python -m alembic upgrade head
   ```
4. 서버를 실행하고 `http://127.0.0.1:8000/signup`을 엽니다.
   ```
   .venv\Scripts\python -m uvicorn --factory web.app:create_app --app-dir src --reload
   ```
5. 가입하면 개발 환경에서는 메일을 보내는 대신 서버 콘솔에 인증 링크를 출력합니다. 그 링크를 브라우저에서 엽니다.

### 시연 서버

개발 PC의 서버를 ngrok으로 열어 참가자가 접속합니다. ngrok 계정과 설치가 필요하고, 시연 때만 열고 바로 닫습니다. 실제 터널로는 아직 확인하지 않았습니다.

```
.venv\Scripts\python ai-agent/scripts/demo_server.py start
.venv\Scripts\python ai-agent/scripts/demo_server.py reset
```

`start`는 터널과 서버를 함께 띄우고 시연 주소를 출력하며, Ctrl+C로 함께 닫힙니다. 메일 없이 가입 즉시 인증됩니다. `reset`은 시연 DB만 지웁니다.

### 데스크톱 앱

외부 패키지 설치는 필요 없습니다.

```
py -3 src/main.py
```

## 웹 서비스 사용 방법

처음에는 **가입 → 이메일 인증 → 단어장 만들기 → 설정 확인 → 일차 만들기 → 암기 → 시험** 순서로 진행합니다.

이메일 인증 전에는 화면을 볼 수만 있고, 단어 추가나 설정 저장 같은 쓰기 기능은 쓸 수 없습니다.

### 홈
- 지금 할 일을 안내합니다. 단어가 없으면 단어장으로, 일차가 끝났으면 "다음 일차 만들기"로, 외우는 중이면 "이어서 암기하기"로 안내합니다.
- 현재 일차와 전체 진행률, 최근 시험 결과를 보여 줍니다.

### 단어장
- 단어와 뜻을 입력하고 "추가"를 누릅니다. 뜻이 여러 개면 `/`로 구분합니다.
- 대소문자만 다른 단어(`Apple`과 `apple`)는 같은 단어로 보고 중복 처리합니다.
- "가져오기": CSV 파일의 단어를 **추가**합니다. 첫 줄은 `word,meaning`이어야 하고, 같은 단어는 건너뜁니다. UTF-8과 CP949를 읽으며, 파일은 5MB, 5,000행까지입니다. 저장소의 `data/words.csv`(1,988개)를 표본으로 쓸 수 있습니다.
- "내보내기": 단어장을 CSV 파일로 내려받습니다.
- 단어를 지우면 진도에서도 빠지고 학습 기록은 남습니다. 같은 단어를 다시 추가하면 기록이 이어집니다.
- 검색 칸은 단어와 뜻을 함께 찾고, 열 제목을 누르면 정렬합니다.

### 암기
- 홈의 "다음 일차 만들기"로 일차를 만듭니다. 현재 일차를 모두 외운 뒤에 만들 수 있습니다.
- 뜻을 본 뒤 "외움" 또는 "다시"를 고릅니다. "다시"는 같은 일차의 맨 뒤로 보냅니다.
- 중간에 나가도 다시 들어오면 아직 외우지 않은 첫 카드부터 이어 갑니다.

| 동작 | 키 |
|------|-----|
| 뜻 보기 | ↑ 또는 Space |
| 외움 | → 또는 1 |
| 다시 | ← 또는 2 |

- 일차 드롭다운으로 지난 일차를 복습할 수 있습니다. 복습은 카드만 넘기고 기록과 진도를 바꾸지 않으며, 새로고침하면 처음부터 시작합니다.
- "일차별 진도 보기": 일차의 단어, 뜻, 구분(신규·복습·오답), 외움 여부를 읽기 전용으로 봅니다.

### 시험
- 형식, 방향, 문항 수를 고르고 "시험 시작"을 누릅니다. 형식과 방향의 기본값은 설정을 따릅니다. 문항 수는 1~200이고, 단어 수보다 크면 단어 수만큼 냅니다.
- 객관식은 단어 4개, 주관식은 단어 1개가 있어야 시작할 수 있습니다.
- 정답은 제출할 때까지 브라우저로 전달되지 않고, 채점은 서버에서 합니다.
- 주관식은 앞뒤 공백과 대소문자를 무시합니다. 뜻이 여러 개면 하나만 맞아도 정답이고, 같은 뜻의 다른 단어도 정답으로 인정합니다.

| 동작 | 키 |
|------|-----|
| 보기 선택 (객관식) | 1~4 |
| 다음 문항, 제출 | Enter |

- 틀린 단어는 오답 횟수가 쌓여 다음 일차의 오답 단어로 나옵니다. 답하지 않은 문항은 점수에서 오답이지만 오답 횟수는 올리지 않습니다.
- 새로고침해도 같은 탭에서는 문항과 답이 유지됩니다. 탭을 닫으면 문제는 남고 답은 사라집니다. 시작 후 24시간이 지나면 폐기됩니다.
- 진행 중인 시험은 하나만 둡니다. 새로 시작하면 확인 뒤 이전 시험을 폐기합니다.
- 결과 화면에서 문항별 정답과 틀린 문항만 볼 수 있습니다. 제출한 시험을 다시 열면 점수만 보여 줍니다.
- "시험 기록": 지난 시험 결과와 전체 정답률을 봅니다.

### 설정
- 하루 신규·복습·오답 수, 오답 기준, 시험 기본 형식·방향을 바꿉니다.
- 신규와 오답 기준은 1 이상, 복습과 오답은 0 이상이며 모두 9999 이하입니다.
- 저장하면 다음 일차 진도부터 적용됩니다. 이미 만든 진도는 바뀌지 않습니다. "되돌리기"는 마지막으로 저장한 값으로 돌아갑니다.

## 데스크톱 앱 사용 방법

기록은 CSV 파일에 저장합니다. 웹과 데이터를 주고받지 않습니다.

### 단어장 탭
- "CSV 불러오기": 단어 파일을 읽어 단어장을 **바꿉니다**. 첫 줄은 `word,meaning`이어야 합니다. 바꾸기 전에 기존 단어장을 `data/backup/`에 백업하며, 백업은 최근 20개만 남깁니다.
- 단어와 뜻을 입력하고 "추가"를 누릅니다. 뜻이 여러 개면 `/`로 구분합니다. 대소문자만 다른 단어는 중복 처리합니다.
- 단어를 고르고 "선택 수정"을 누르거나 더블클릭합니다. "선택 삭제"는 모든 일차의 진도에서도 빼고 학습 기록은 남깁니다.
- 검색 칸에 단어나 뜻을 입력하면 걸러서 보여 줍니다. 열 제목을 누르면 정렬됩니다.

### 암기 탭
- "다음 일차 만들기": 새 일차의 진도를 만듭니다. 현재 일차를 모두 외운 뒤에 누를 수 있습니다.
- 카드 단축키: **↑** 뜻 보기, **→** 외움, **←** 다시
- "일차별 진도": 지난 일차의 단어와 외움 여부를 봅니다. 읽기 전용입니다.

### 시험 탭
- 형식, 방향, 문항 수를 고르고 "시험 시작"을 누릅니다.
- 객관식은 **1~4** 키로 보기를 고르고, **Enter**로 제출하거나 다음 문항으로 넘어갑니다.
- "시험 기록": 지난 시험 결과와 전체 정답률을 봅니다.

### 설정 탭
- 하루 신규·복습·오답 수, 오답 기준, 시험 기본 형식·방향을 바꿉니다. 저장하면 다음 일차 진도부터 적용됩니다.

## 테스트

프로젝트 루트에서 실행합니다.

```
.venv\Scripts\python -m unittest discover -s tests
```

- 웹 테스트 (`tests/web_tests/`): 332개
- 데스크톱 단위 테스트 (핵심 로직, 저장소, 파일 저장과 백업): 51개
- 데스크톱 화면 흐름 테스트 (`tests/test_gui_flow.py`): 8개
- 합계 391개

웹 화면 동작은 실제 브라우저로 따로 점검합니다 (Chrome 또는 Edge 필요). 임시 DB를 쓰며, `--keep`을 붙이면 스크린샷이 남습니다.

```
.venv\Scripts\python ai-agent/scripts/browser_check.py
```

테스트는 임시 폴더를 쓰므로 `data/` 파일을 바꾸지 않습니다. 화면을 띄울 수 없는 환경에서는 데스크톱 화면 테스트가 건너뛰어집니다.
