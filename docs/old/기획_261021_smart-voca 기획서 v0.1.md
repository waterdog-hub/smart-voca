## 1. 프로젝트 개요

- **프로젝트명**: smart-voca (단어장 프로그램)
- **한 줄 설명**: 단어 목록을 관리하고, 설정에 따라 일자별 암기 진도를 자동 생성하여 암기와 시험을 제공하는 영↔한 단어장
- **상태**: 기획 초안 (미승인)

## 2. 목적과 사용자

### 2.1 목적
- 단어 목록을 파일로 불러오고 저장하여 단어장을 쉽게 관리한다.
- 하루 학습량에 맞춰 일차별 암기 진도를 자동으로 만들어 꾸준한 암기를 돕는다.
- 복습과 시험으로 암기 여부를 확인하고, 자주 틀린 단어를 집중 복습하게 한다.

### 2.2 사용자
- 영어 단어를 암기하려는 개인 학습자 (주 사용자)
- 학습 언어 쌍: **영 ↔ 한** (영→한, 한→영 양방향)

## 3. 기능 범위

### 3.1 1차 범위 (이번 버전)

| ID | 기능 | 설명 |
|----|------|------|
| F-01 | 단어 목록 불러오기 | 파일에서 단어 목록을 읽어 단어장에 등록 (형식: 확정 필요, §6 참고) |
| F-02 | 단어 목록 저장 | 현재 단어장을 파일로 저장 |
| F-03 | 설정 | 하루 학습 단어 수, 복습 포함 규칙 등 학습 설정 관리 |
| F-04 | 진도 생성 | 설정에 따라 1일차, 2일차 … 순으로 암기 진도를 자동 생성 |
| F-05 | 암기 기능 | 일차별 진도 단어를 카드 형태로 외우고 학습 여부를 기록 |
| F-06 | 단어 시험 기능 | 단어를 대상으로 뜻 맞히기 시험을 보고 결과를 기록 |
| F-07 | 오답 기록 | 시험에서 틀린 단어를 누적 기록 |

### 3.2 진도 생성 규칙 (F-04 상세)

일차별 진도는 다음 규칙으로 구성한다.

1. **신규 단어**: 설정한 `하루 학습 단어 수(N)`만큼 아직 외우지 않은 단어를 배정한다.
2. **전날 복습 단어**: 전날 외운 단어 중 일부를 다음 날 진도에 추가한다. 비율 또는 개수는 설정으로 정한다.
3. **자주 틀린 단어**: 오답 횟수가 기준 이상인 단어를 진도에 추가한다. 기준과 최대 개수는 설정으로 정한다.
4. 같은 단어가 한 날 진도에 중복 배정되지 않도록 한다.
5. 단어장의 모든 단어를 외운 뒤에는 복습 단어만으로 진도를 구성한다. (세부 동작은 §6 확인 필요)

**예시 (N=20, 전날 복습 5개, 오답 기준 2회 이상 최대 3개 가정)**
- 1일차: 신규 20개
- 2일차: 신규 20개 + 1일차 단어 중 5개 + 오답 단어 중 3개 = 28개 (신규 단어 수는 이 예시 기준임)

> 복습과 오답 단어를 신규 N개에 포함할지, 별도로 더할지는 §6에서 확정한다.

### 3.3 제외 범위 (이번 버전에서 하지 않음)

- 발음 음성 재생
- 외부 사전 API 연동 (단어 뜻 자동 조회)
- 로그인, 계정, 기기 간 동기화
- 학습 통계 그래프 (기본 기록만 저장)

> 제외 범위는 제안이며 확정이 필요하다.

## 4. 데이터 정의 (초안)

| 항목 | 설명 | 비고 |
|------|------|------|
| 단어(word) | 영문 단어 | 필수 |
| 뜻(meaning) | 한글 뜻 | 필수, 여러 개 허용 여부 확정 필요 |
| 품사, 예문 | 부가 정보 | 선택 항목 |
| 학습 기록 | 외운 날짜, 외운 횟수 | 진도 생성에 사용 |
| 오답 기록 | 시험 오답 횟수, 최근 오답일 | 자주 틀린 단어 판정에 사용 |
| 설정 | 하루 단어 수, 복습 수, 오답 기준, 오답 최대 수 | 기본값 §6 확정 필요 |

데이터 저장 방식은 §6에서 정한다.

## 5. 비기능 요구사항 (초안)

- 개인정보(실명, 연락처 등)를 저장하지 않는다.
- 단어 데이터 원본 파일은 `data/`에 두고, 큰 파일은 커밋하지 않는다.
- 학습 설정은 코드에 하드코딩하지 않고 설정 파일로 관리한다.
