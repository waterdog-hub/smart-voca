## 1. 전제

- 기준 문서는 구현 계획 §6이다. 이 문서는 그 구성을 실제 테스트 파일과 결과로 구체화한다.
- 자동 테스트는 임시 폴더의 SQLite를 쓰며 `data/`를 바꾸지 않는다.
- 자동 테스트 실행 (프로젝트 루트): `.venv\Scripts\python -m unittest discover -s tests`
- 브라우저 점검 실행 (프로젝트 루트): `.venv\Scripts\python ai-agent/scripts/browser_check.py`

## 4. 브라우저 점검 목록

자동 테스트는 자바스크립트를 실행하지 않으므로 아래 항목은 실제 브라우저로 확인한다. `ai-agent/scripts/browser_check.py`가 실제 uvicorn, 마이그레이션한 임시 DB, 헤드리스 Chrome(또는 Edge)으로 §4.1~§4.3을 점검한다 (57개 항목, 2026-11-04 전부 통과). `--keep`을 붙이면 스크린샷과 서버 로그가 남는다. 레이아웃 결함은 스크린샷을 봐야 찾을 때가 있으므로 화면을 바꾼 마일스톤에서는 함께 확인한다.

### 4.1 인증 (M2)
- [x] 로그인 없이 회원 화면을 열면 로그인 화면으로 이동한다
- [x] 흔한 비밀번호로 가입하면 칸 아래에 오류가 나오고 버튼이 다시 활성화된다

- [x] 세션 쿠키는 자바스크립트에서 읽을 수 없다
- [x] 1분 안의 재발송은 남은 시간을 안내한다

## 5. 검증하지 못한 범위

| 범위 | 현재 상태 | 확인 시점 |
|------|-----------|-----------|
| 시연 환경의 재설정 안내 | 단위 테스트로만 확인. 시연 점검 도구에는 넣지 않음. 재설정 메일 자체는 시연에서 쓰지 않는다 | 시연 전 |
| 실제 메일의 재설정 링크 | 개발용 콘솔 메일로만 확인. 운영 발송은 M10 | M10 |
| 단어장 담기·제외의 부하 | 요청 횟수 제한이 없다. 큰 단어장(5,000행)의 담기·제외 시간은 측정하지 않음 | M10 |
| 단어장 출처 | 표본 `data/words.csv`의 출처·라이선스 미확인 | 공개 전 |
| PostgreSQL | 모든 테스트가 SQLite. PostgreSQL용 DDL 생성만 확인했고 실행은 안 함. 드라이버 미설치 | M10 전 |
| 시연 터널의 남은 범위 | 2026-11-05 리허설은 기기 2대가 차례로 접속했다. 여러 명 동시 접속, 실제 터널에서의 로그인 잠금, `demo_server.py`의 Ctrl+C 종료는 확인하지 않음 | Ctrl+C는 시연 전 점검. 나머지는 시연 때 관찰 |
| 실제 메일 발송 | 개발용 콘솔 출력과 기록용 구현만 확인. 운영 구현 없음 | M10 |
| 프록시 환경 | 프록시 헤더, 요청 크기 제한, HTTPS, Secure 쿠키의 실제 전송 미확인 | M10 |
| 동시 요청 | 충돌 처리는 시점을 조작해 확인했고 실제 병렬 부하는 안 함 | M10 |
| CHECK 제약 변경 | `alembic check`가 감지하지 못함 (구현 계획 D-IMP10). 수동 작성 필요 | 변경 시마다 |
| 회귀 자동화 | 브라우저 점검은 `unittest` 명령에 포함되지 않음 (브라우저가 필요하고 시간이 걸림). 화면을 바꾼 마일스톤마다 따로 실행 | 마일스톤마다 |
