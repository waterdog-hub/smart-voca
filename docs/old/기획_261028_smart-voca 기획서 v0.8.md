**설명**: 영↔한 단어장 프로그램의 목적, 기능 범위, 진도 생성 규칙, 확정 사항을 정리한 기획서

## 1. 프로젝트 개요

- **프로젝트명**: smart-voca (단어장 프로그램)
- **성격**: ICT 폴리텍대학 AI 활용 코딩 실습 수업의 실습 과제 (일정은 공지 전, 제출 형식은 소스 코드 + 설계·테스트 문서)
- **작성자**: 학생 본인
- **한 줄 설명**: 단어 목록을 관리하고, 설정에 따라 일자별 암기 진도를 자동 생성하여 암기와 시험을 제공하는 영↔한 단어장
- **상태**: 기획 초안 (미승인). 구현은 완료되어 화면 동작 확인까지 끝남 (2026-10-28)

## 2. 목적과 사용자

### 2.1 목적
- 단어 목록을 CSV 파일로 불러오고 저장하여 단어장을 쉽게 관리한다.
- 하루 학습량에 맞춰 일차별 암기 진도를 자동으로 만들어 꾸준한 암기를 돕는다.
- 복습과 시험으로 암기 여부를 확인하고, 자주 틀린 단어를 집중 복습하게 한다.

### 2.2 사용자
- 영어 단어를 암기하려는 개인 학습자 (주 사용자)
- 학습 언어 쌍: **영 ↔ 한**

## 3. 기능 범위

### 3.1 1차 범위

| ID | 기능 | 설명 |
|----|------|------|
| F-01 | 단어 목록 불러오기 | CSV 파일에서 단어 목록을 읽어 단어장에 등록 |
| F-02 | 단어 목록 저장 | 현재 단어장을 CSV 파일로 저장 |
| F-03 | 설정 | 하루 학습 구성(신규·복습·오답 수), 오답 기준, 시험 형식·방향 관리. 설정은 CSV로 저장 |
| F-04 | 진도 생성 | 설정에 따라 1일차, 2일차 … 순으로 암기 진도를 자동 생성 |
| F-05 | 암기 기능 | 일차별 진도 단어를 카드 형태로 외우고 학습 여부를 기록 |
| F-06 | 단어 시험 기능 | 아래 3.4의 시험 형식·방향을 선택해 시험을 보고 결과를 기록 |
| F-07 | 오답 기록 | 시험에서 틀린 단어를 누적 기록 |
| F-08 | 단어 편집 | 단어와 뜻을 고치고, 단어를 지운다. 지우면 모든 일차의 진도에서도 빠진다 (3.8) |
| F-09 | 단어 검색·정렬 | 단어나 뜻으로 검색하고, 열 제목으로 정렬한다 |
| F-10 | 시험 기록 | 시험 결과를 날짜별로 저장하고, 기록 화면에서 보여준다 (정답률 포함) |
| F-11 | 일차별 진도 보기 | 지난 일차의 단어와 외움 여부를 읽기 전용으로 보여준다 |
| F-12 | 키보드 조작 | 암기와 시험을 방향키·숫자키·Enter로 조작한다 (3.8) |

### 3.2 기술 스택 (확정)

- **언어**: Python
- **GUI**: tkinter (Python 표준 라이브러리, 별도 설치 불필요)
- **저장**: CSV (단어, 설정, 학습 기록 모두)

### 3.3 파일 형식 (F-01, F-02, F-03, 학습 기록)

**단어 파일**
- 형식: **CSV** (UTF-8), 첫 줄은 헤더
- 열 구성: `word,meaning`
- 뜻이 여러 개인 경우 `/`로 구분한다. (예: `run,달리다/운영하다`)

**설정 파일 · 학습 기록 파일**
- 형식: **CSV** (UTF-8)
- 설정 파일은 항목명과 값의 두 열로 저장한다. (예: `key,value`)
- 학습 기록 파일은 단어별 학습 날짜, 외운 횟수, 시험 오답 횟수, 최근 오답일을 저장한다.

### 3.4 단어 시험 상세 (F-06)

**시험 형식** (선택 가능)
- **객관식**: 보기 중 정답 선택
- **주관식**: 답을 직접 입력

**시험 방향** (선택 가능)
- **영 → 한**: 영어 단어를 보고 한글 뜻을 맞힌다.
- **한 → 영**: 한글 뜻을 보고 영어 단어를 맞힌다.
- **양방향**: 영→한과 한→영을 함께 출제한다.

형식과 방향은 조합해서 설정할 수 있다. (예: 주관식 + 한→영)

### 3.5 진도 생성 규칙 (F-04 상세)

**하루 진도 구성 (기본값)**

| 구분 | 개수 | 선정 기준 |
|------|------|-----------|
| 신규 단어 | 20개 | 아직 외우지 않은 단어 중 순서대로 |
| 복습 단어 | 5개 | 전날 외운 단어 중에서 선정 |
| 오답 단어 | 5개 | 오답 횟수가 **3회 이상**인 단어 중에서 오답 횟수가 많은 순 |
| **합계** | **30개** | |

개수와 오답 기준은 설정 파일에서 바꿀 수 있다.

**규칙 (모든 단어를 한 번씩 외우기 전)**
1. 신규 단어는 단어장 순서대로 배정한다.
2. 복습 단어는 전날 외운 단어에서 5개를 고른다.
3. 오답 단어는 오답 3회 이상인 단어에서 5개를 고른다. 대상이 5개보다 적으면 있는 만큼만 넣는다.
4. 같은 단어가 한 날 진도에 두 번 들어가지 않도록 한다.

**예시 (1일차, 2일차)**
- 1일차: 신규 20개 (복습·오답 없음)
- 2일차: 신규 20개 + 1일차 단어 중 복습 5개 + 오답 단어 중 5개 = 최대 30개

### 3.6 전체 단어 소진 후 동작 (확정)

- 단어장의 모든 단어를 한 번씩 외운 뒤에는 **오답 중심으로 진도를 계속 진행**한다.
- 진도 구성:
  1. **오답 단어**: 오답 횟수가 **3회 이상**인 단어를 대상으로, 오답 횟수가 많은 순으로 배정한다. (기본 5개)
  2. **복습 단어**: 오답 대상이 부족하면 남은 칸을 복습 단어로 채운다. (기본 5개 중 부족분)
- 신규 단어는 더 이상 배정하지 않는다.

> 오답 기준은 **3회 이상으로 통일**했다. 평시와 소진 후 모두 같은 설정값(`wrong_threshold`)을 사용한다.

### 3.7 제외 범위 (이번 버전에서 하지 않음)

- 발음 음성 재생
- 외부 사전 API 연동 (단어 뜻 자동 조회)
- 로그인, 계정, 기기 간 동기화
- 학습 통계 그래프 (정답률 숫자만 보여준다)
- 삭제한 단어 복구 (삭제 확인창으로 막는다)

> 제외 범위는 제안이며 확정이 필요하다.

### 3.8 편집·시험 기록·조작 (v0.8 추가)

**단어 편집 (F-08, F-09)**
- 단어장에서 단어와 뜻을 고칠 수 있다. 더블클릭 또는 "선택 수정" 버튼을 쓴다.
- 단어 이름을 바꾸면 학습 기록과 진도의 단어 이름도 함께 바뀐다. 뜻만 바꾸면 기록과 진도는 그대로다.
- 중복 단어는 추가와 수정 모두에서 막는다.
- 단어를 지우기 전에 확인창을 띄운다. 지운 단어는 **모든 일차의 진도에서 빠진다.** 학습 기록은 남긴다.
- 검색은 단어와 뜻 모두에서 찾는다. 대소문자는 구분하지 않는다.
- 열 제목을 누르면 정렬하고, 같은 열을 다시 누르면 역순으로 바꾼다.
- CSV 불러오기로 단어장을 바꾸면, 새 파일에 없는 단어도 같은 규칙으로 진도에서 빠진다.

**시험 기록 (F-10)**
- 시험이 끝나면 형식, 방향, 문항 수, 정답 수, 시각을 기록 파일에 한 줄 남긴다.
- 시험 탭의 "시험 기록" 창에서 최근 순으로 보여주고, 전체 정답률을 표시한다.

**일차별 진도 (F-11)**
- 암기 탭의 "일차별 진도" 창에서 일차를 골라 단어, 뜻, 구분(신규·복습·오답), 외움 여부를 본다. 수정은 할 수 없다.

**키보드 조작 (F-12)**
- 암기: ↑ 뜻 보기, → 외움, ← 다시
- 시험: 1~4로 보기 선택(객관식), Enter로 제출 또는 다음 문항
- 입력칸에 커서가 있거나 다른 창이 열려 있으면 단축키는 동작하지 않는다.
- 암기와 시험에 진행률 막대를 표시한다.

## 4. 데이터 정의 (초안)

| 항목 | 설명 | 비고 |
|------|------|------|
| 단어(word) | 영문 단어 | 필수, CSV `word` 열 |
| 뜻(meaning) | 한글 뜻, 여러 개면 `/` 구분 | 필수, CSV `meaning` 열 |
| 학습 기록 | 외운 날짜, 외운 횟수 | 학습 기록 CSV |
| 오답 기록 | 시험 오답 횟수, 최근 오답일 | 학습 기록 CSV, 자주 틀린 단어 판정에 사용 |
| 설정 | 신규 수(20), 복습 수(5), 오답 수(5), 오답 기준(3회), 시험 형식·방향 | 설정 CSV |

## 5. 비기능 요구사항 (초안)

- 실행 환경은 Windows이며, 언어는 Python이다.
- 개인정보(실명, 연락처 등)를 저장하지 않는다.
- 단어 데이터 원본 파일은 `data/`에 두고, 큰 파일은 커밋하지 않는다.
- 학습 설정은 코드에 하드코딩하지 않고 설정 CSV로 관리한다. (코드의 기본값은 설정 파일이 없을 때만 사용)
