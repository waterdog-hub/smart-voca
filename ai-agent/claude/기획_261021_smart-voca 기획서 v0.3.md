## 1. 프로젝트 개요

- **프로젝트명**: smart-voca (단어장 프로그램)
- **성격**: ICT 폴리텍대학 AI 활용 코딩 실습 수업의 교수님 실습 과제
- **작성자**: 학생 본인 (학번·이름은 제출 시 기입)
- **한 줄 설명**: 단어 목록을 관리하고, 설정에 따라 일자별 암기 진도를 자동 생성하여 암기와 시험을 제공하는 영↔한 단어장
- **상태**: 기획 초안 (미승인)

## 2. 목적과 사용자

### 2.1 목적
- 단어 목록을 CSV 파일로 불러오고 저장하여 단어장을 쉽게 관리한다.
- 하루 학습량에 맞춰 일차별 암기 진도를 자동으로 만들어 꾸준한 암기를 돕는다.
- 복습과 시험으로 암기 여부를 확인하고, 자주 틀린 단어를 집중 복습하게 한다.

### 2.2 사용자
- 영어 단어를 암기하려는 개인 학습자 (주 사용자)
- 학습 언어 쌍: **영 ↔ 한**

## 3. 기능 범위

### 3.1 1차 범위

| ID | 기능 | 설명 |
|----|------|------|
| F-01 | 단어 목록 불러오기 | CSV 파일에서 단어 목록을 읽어 단어장에 등록 |
| F-02 | 단어 목록 저장 | 현재 단어장을 CSV 파일로 저장 |
| F-03 | 설정 | 하루 학습 단어 수, 복습 포함 수, 오답 기준, 오답 최대 수, 시험 형식·방향 관리 |
| F-04 | 진도 생성 | 설정에 따라 1일차, 2일차 … 순으로 암기 진도를 자동 생성 |
| F-05 | 암기 기능 | 일차별 진도 단어를 카드 형태로 외우고 학습 여부를 기록 |
| F-06 | 단어 시험 기능 | 아래 3.2의 시험 형식·방향을 선택해 시험을 보고 결과를 기록 |
| F-07 | 오답 기록 | 시험에서 틀린 단어를 누적 기록 |

### 3.2 단어 파일 형식 (F-01, F-02)

- 형식: **CSV** (UTF-8)
- 열 구성: `word,meaning` (영문 단어, 한글 뜻)
- 첫 줄은 헤더 행으로 간주한다.
- 예시:
  ```
  word,meaning
  apple,사과
  book,책
  ```
- 뜻이 여러 개인 경우의 처리(구분자 등)는 §6 Q-03에서 정한다.

### 3.3 단어 시험 상세 (F-06)

**시험 형식** (선택 가능)
- **객관식**: 보기 중 정답 선택
- **주관식**: 답을 직접 입력

**시험 방향** (선택 가능)
- **영 → 한**: 영어 단어를 보고 한글 뜻을 맞힌다.
- **한 → 영**: 한글 뜻을 보고 영어 단어를 맞힌다.
- **양방향**: 영→한과 한→영을 함께 출제한다.

형식과 방향은 조합해서 설정할 수 있다. (예: 주관식 + 한→영)

### 3.4 진도 생성 규칙 (F-04 상세)

일차별 진도는 다음 규칙으로 구성한다.

1. **신규 단어**: 설정한 `하루 학습 단어 수(N)`만큼 아직 외우지 않은 단어를 배정한다.
2. **전날 복습 단어**: 전날 외운 단어 중 **기본 10개**를 다음 날 진도에 추가한다. 개수는 설정으로 바꿀 수 있다.
3. **자주 틀린 단어**: 오답 횟수가 **3회 이상**인 단어를 진도에 추가한다. 최대 추가 개수는 **기본 10개**이며 설정으로 바꿀 수 있다.
4. 같은 단어가 한 날 진도에 중복 배정되지 않도록 한다.
5. 단어장의 모든 단어를 외운 뒤의 동작은 §6 Q-09에서 정한다.

**예시 (N=20, 복습 10개, 오답 기준 3회 이상 최대 10개 기본값 적용)**
- 1일차: 신규 20개
- 2일차: 신규 20개 + 1일차 단어 중 10개 + 오답 단어 중 최대 10개 = 최대 40개 (신규 단어 수는 이 예시 기준임)

> 복습과 오답 단어를 신규 N개에 포함할지, 별도로 더할지는 §6 Q-08에서 정한다.

### 3.5 제외 범위 (이번 버전에서 하지 않음)

- 발음 음성 재생
- 외부 사전 API 연동 (단어 뜻 자동 조회)
- 로그인, 계정, 기기 간 동기화
- 학습 통계 그래프 (기본 기록만 저장)

> 제외 범위는 제안이며 확정이 필요하다.

## 4. 데이터 정의 (초안)

| 항목 | 설명 | 비고 |
|------|------|------|
| 단어(word) | 영문 단어 | 필수, CSV `word` 열 |
| 뜻(meaning) | 한글 뜻 | 필수, CSV `meaning` 열 |
| 학습 기록 | 외운 날짜, 외운 횟수 | 진도 생성에 사용 |
| 오답 기록 | 시험 오답 횟수, 최근 오답일 | 자주 틀린 단어 판정에 사용 |
| 설정 | 하루 단어 수(N), 복습 수(10), 오답 기준(3회), 오답 최대 수(10), 시험 형식·방향 | 기본값 위와 같음 |

학습 기록과 오답 기록, 설정을 저장하는 형식(CSV, JSON 등)은 §6 Q-02에서 정한다.

## 5. 비기능 요구사항 (초안)

- 실행 환경은 Windows이며, 언어는 Python이다.
- 개인정보(실명, 연락처 등)를 저장하지 않는다.
- 단어 데이터 원본 파일은 `data/`에 두고, 큰 파일은 커밋하지 않는다.
- 학습 설정은 코드에 하드코딩하지 않고 설정 파일로 관리한다.
