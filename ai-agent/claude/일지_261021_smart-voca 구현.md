## 구현 중 발생한 문제
- `python` 명령이 이 PC에서 실행되지 않음(종료 코드 9009). `py -3`으로 대체. CLAUDE.md에 기록.
- 테스트를 `-t .` 옵션으로 실행하면 import 오류 발생. 프로젝트 루트에서 `-s tests`만 지정하면 정상.
- 콘솔 출력의 한글이 깨져 보임(cp949 콘솔). 파일은 `utf-8-sig`로 저장되므로 데이터 문제는 아님.
