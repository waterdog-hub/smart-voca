## D-VOCA02 학교 서버 모드 (`APP_ENV=school`)

- **배경**: 학교 서버는 메일·인터넷이 없고 `https` 주소와 `AUTH_HASH_KEY` 를 주지 않는다. 기존 `production` 모드는 메일 인증 필수, `https` 필수라 가입할 수 없다.
- **대안**: (1) 서버용 모드에서만 가입 즉시 인증 (2) 메일 인증을 모든 환경에서 없앰
- **결정**: (1) 사용자 선택. `school` 모드는 가입 즉시 인증, 쿠키 `Secure` 생략(http 접속 대비), API 문서 닫음, 소셜 로그인 끔.
- **근거**: 기존 개발·시연·운영 동작과 테스트를 그대로 둔다. 키는 `SECRET_KEY` 로 만들고, 없으면 무작위로 만들어 `/data/.secret_key` 에 둔다. 이메일 해시가 재시작마다 바뀌면 로그인할 수 없기 때문이다.

## D-VOCA03 단어 직접 등록·CSV 가져오기와 중복 처리

- **배경**: VOCA-FR-001~003은 기본 기능인데, 이슈 #17(D-WB04)로 회원의 단어 쓰기를 없앴었다.
- **대안**: (1) 공용 단어장 유지 + 내 단어 직접 등록 추가 (2) 공용 단어장을 없애고 직접 등록만
- **결정**: (1) 사용자 선택.
- **중복 규칙**: 대소문자 무시(D-24). 직접 등록·수정은 409로 알림. CSV는 기존 단어와 파일 안 중복을 건너뛰고 기존 뜻은 바꾸지 않는다(D-WB06과 같은 원칙). 지운 단어를 다시 등록하면 그 행을 되살려 학습 기록을 잇는다.
- **알려진 위험**: 직접 등록한 단어가 담은 공용 단어장에도 있으면, 그 단어장을 제외할 때 함께 빠질 수 있다.

## D-VOCA04 주소 규칙 (R-04)

- **배경**: 서버 앞단 nginx는 `fetch("/`, `href = "/`, `url(/` 처럼 정해진 모양의 문자열만 바꾼다.
- **결정**: JS는 `fetch("/api/…", jsonRequest(…))` 처럼 호출 자리에 문자열로 쓰고, 이동은 `window.location.href = "/…"` 로 통일한다. CSS `url("/…")` 은 따옴표를 뺀다. 로그인 뒤 돌아갈 주소(`next`)는 앱 안 경로로 두고, `<link rel="home" href="/">`(서버가 바꿔 줌)로 앱 시작 주소를 알아내 앞에 붙인다.
- **대안**: 주소 앞부분을 변수로 두는 방식은 규칙 위반이라 쓰지 않는다.
