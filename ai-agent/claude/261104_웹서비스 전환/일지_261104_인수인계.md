## 2. 확정된 방향 (사용자 답변)

|------|------|

| 서비스 범위 | 공개 인터넷 서비스 |
| 데스크톱 앱 | 웹으로 대체 |
| 프런트엔드 | 서버 템플릿(Jinja2) + 필요한 부분만 자바스크립트 |

## 6. 주의 사항

- `core.autocrlf=input`과 Git 작성자 설정은 `.git/config`에만 있어서 복제 후 다시 설정해야 한다.
- 작성자 변경 전 기록의 백업(`refs/original`, 태그 `backup/pre-author-rewrite`)은 M2 커밋에서 작성자를 확인한 뒤 2026-11-04에 지웠다.
- GitHub에 옛 작성자 이름이 남아 있다. 병합된 PR #1(`refs/pull/1/head`) 커밋 9개가 참조로 남아 있고, 기록 변경 전 커밋 41개도 커밋 번호로 직접 열린다. `refs/pull/`은 읽기 전용이라 push로 지울 수 없어(2026-11-04 시도, 서버 거절) GitHub 지원팀 요청이 필요하다. 사용자가 지원팀에 요청하기로 했다. 처리되면 PR #1이 삭제될 수 있다.
- Claude 메모리와 대화 기록은 옮겨지지 않는다. 필요한 맥락은 이 문서와 설계 문서에 있다.
- `.env`, `.venv/`와 `data/`의 실행 데이터(`settings.csv`, `study_record.csv`, `day_plan.csv`, `test_history.csv`, `backup/`)는 Git에서 제외되어 있다. `data/words.csv`는 저장소에 있다. 웹 전환은 새로 시작하므로 실행 데이터를 옮길 필요가 없다.
- 2026-11-04에 커밋 작성자를 바꿔 기록을 다시 썼다. 그 전에 복제한 PC는 `git pull` 대신, 올리지 않은 작업이 없는지 확인한 뒤 `git fetch` 후 `git reset --hard origin/main`으로 맞춘다.
- 두 PC에서 동시에 작업하지 않는다. 시작 전 `git pull`, 끝나면 커밋과 push.
- 파일 수정, 커밋, push, 패키지 설치, 일반 이슈 생성은 CLAUDE.md에 따라 사용자 승인 후에 한다. 결정 이유 이슈는 상시 승인되어 있다 (CLAUDE.md 이슈 관리 5번).
