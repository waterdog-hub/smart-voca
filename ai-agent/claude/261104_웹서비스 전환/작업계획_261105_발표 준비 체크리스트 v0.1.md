## 7. 문제가 생기면

| 상황 | 조치 |
|------|------|
| 터널이 안 열림 | 휴대폰 핫스팟으로 바꿔 다시 `start`. 안 되면 4번 영상 |
| 참가자가 접속 못 함 | 시연 계정으로 앞에서만 시연하고, 영상 병행 |
| 시연 데이터가 꼬임 | Ctrl+C → `reset` → `start` → `demo_prepare.py 새주소` (2분). 주소가 바뀌므로 QR도 다시 만든다 |
| QR이 안 읽힘 | 주소 글자를 크게 읽어 준다 (3번 슬라이드의 큰 글자) |
| 영상이 재생 안 됨 | 슬라이드 쇼 모드인지 확인. 안 되면 `발표/assets/demo.mp4`를 직접 연다 |
| 비밀번호 재설정을 묻는 질문 | 시연 환경은 메일을 보내지 않아 쓸 수 없다고 답한다 (이슈 #18) |
